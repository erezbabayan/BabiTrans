# Privacy (BabiTrans)
Audio is transcribed **on the device** by default and never leaves it. No ads, analytics, crash reporting, accounts or third-party SDKs. Internet is used only to download the model from GitHub Releases, and — only if you configure it and enable "prefer server" — to send audio to **your own** matamel server. Full policy (Hebrew): [docs/PRIVACY_HE.md](docs/PRIVACY_HE.md).
