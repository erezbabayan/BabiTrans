# BabiTrans · מתמלל — התקנה
1. בטלפון (S23) פתחו: https://github.com/erezbabayan/BabiTrans/releases/latest/download/BabiTrans.apk
2. הורידו → התקינו (אשרו "התקנה ממקורות לא ידועים").
3. בפתיחה הראשונה: הגדרות → כתובת שרת (HTTPS) + טוקן X-Matamel-Token אם יש.
4. בוואטסאפ: לחיצה ארוכה על הודעה קולית → שיתוף → BabiTrans → התמלול מופיע → "העתק".

הערה: כדי שהתמלול יעבוד בלי המחשב הביתי, הכתובת חייבת להצביע לשרת HTTPS שזמין תמיד.
כתובת LAN כמו http://10.0.0.8:PORT עובדת רק כשהמחשב דולק ובאותה רשת Wi‑Fi.

## גרסה 0.3 — מהירות
- ברירת מחדל: מודל **מהיר** (ivrit‑ai turbo q4_0, ~450MB, הורדה חד‑פעמית). להודעה של ~6 שניות התמלול מהיר פי ~5–9 מגרסה 0.2.
- המנוע מעבד רק את אורך ההקלטה בפועל (ולא חלון קבוע של 30 שניות), בלי חזרות fallback, ב‑6 ליבות.
- המודל נטען ברקע עם פתיחת האפליקציה ונשאר בזיכרון בין שיתופים.
- התמלול מועתק אוטומטית ללוח וקופץ כהתראה — אפשר לשתף ולחזור לפגישה.
- הגדרות → "איכות גבוהה" משתמש במודל q5 של 0.2 (איטי יותר). מי ששדרג מ‑0.2 ממשיך לעבוד מיד עם q5 עד שיוריד את המודל המהיר.

## גרסה 0.3.2 — אבטחה, פרטיות ותחזוקה (מיושר עם BabiSnap/BabiTk)
- הגדרות → קישורים ל**פרטיות**, **אבטחה ועדכונים**, **תנאי שימוש**, וכפתור **"מחק את כל הנתונים מהמכשיר"**.
